# Automation Tool

Python tool for cleaning and analyzing CSV files.

## Features
- Remove duplicate rows
- Remove empty rows
- Trim whitespace
- Analyze row/column structure
- Count empty cells
- Detect rows with incorrect column counts
- Generate a cleanup report

## Commands
- exit: Exits out of the program.
- clean up: Cleans the selected CSV file and save the result to cleaned.csv.
- analyze: Analyzes the selected file and reports rows, columns, duplicates, empty rows, and empty cells.
